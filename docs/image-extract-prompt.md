# Image Extract Prompt (Vision LLM)

이 문서는 `src/services/image_stock_extractor.py`에 있는 `EXTRACT_PROMPT`의 전체 내용을 기록합니다. PR 리뷰 때 지시문이 어떤 효과를 내는지 판단하기 쉽게 하려는 목적입니다.

**EXTRACT_PROMPT를 수정할 때**: 이 파일도 함께 업데이트하고, PR 설명에 변경 전/후(before/after) 전체를 보여 주십시오. 리뷰어가 code+name+confidence 추출이 얼마나 개선되었는지 판단할 수 있어야 합니다.

---

## 현재 Prompt (전체)

> 아래 코드 블록은 프로그램이 Vision LLM에 실제로 보내는 원문입니다. 소스 코드와 글자 하나까지 같아야 하므로 중국어 그대로 둡니다.

```
请分析这张股票市场截图或图片，提取其中所有可见的股票代码及名称。

重要：若图中同时显示股票名称和代码（如自选股列表、ETF 列表），必须同时提取两者，每个元素必须包含 code 和 name 字段。

输出格式：仅返回有效的 JSON 数组，不要 markdown、不要解释。
每个元素为对象：{"code":"股票代码","name":"股票名称","confidence":"high|medium|low"}
- code: 必填，股票代码（A股6位、港股5位、美股1-5字母、ETF 如 159887/512880）
- name: 若图中有名称则必填（如 贵州茅台、银行ETF、证券ETF），与代码一一对应；仅当图中确实无名称时可省略
- confidence: 必填，识别置信度，high=确定、medium=较确定、low=不确定

示例（图中同时有名称和代码时）：
- 个股：600519 贵州茅台、300750 宁德时代
- 港股：00700 腾讯控股、09988 阿里巴巴
- 美股：AAPL 苹果、TSLA 特斯拉
- ETF：159887 银行ETF、512880 证券ETF、512000 券商ETF、512480 半导体ETF、515030 新能源车ETF

输出示例：[{"code":"600519","name":"贵州茅台","confidence":"high"},{"code":"159887","name":"银行ETF","confidence":"high"}]

禁止只返回代码数组如 ["159887","512880"]，必须使用对象格式。若未找到任何股票代码，返回：[]
```

### 한국어 번역 (참고용)

> 이해를 돕기 위한 번역일 뿐이며, 프로그램은 이 번역을 사용하지 않습니다. 실제로 전송되는 것은 위의 중국어 원문입니다.

```
이 주식 시장 스크린샷 또는 이미지를 분석해 보이는 모든 종목 코드와 종목명을 추출하십시오.

중요: 이미지에 종목명과 코드가 함께 표시되어 있으면(예: 관심 종목 목록, ETF 목록) 반드시 둘 다 추출해야 하며, 모든 요소에 code와 name 필드가 있어야 합니다.

출력 형식: 유효한 JSON 배열만 반환하십시오. markdown이나 설명은 넣지 마십시오.
각 요소는 객체입니다: {"code":"종목 코드","name":"종목명","confidence":"high|medium|low"}
- code: 필수. 종목 코드(A주 6자리, 홍콩 주식 5자리, 미국 주식 영문 1-5자, ETF는 159887/512880 등)
- name: 이미지에 이름이 있으면 필수(예: 贵州茅台(구이저우마오타이), 银行ETF(은행 ETF), 证券ETF(증권 ETF)). 코드와 하나씩 짝지어야 하며, 이미지에 정말 이름이 없을 때만 생략할 수 있습니다.
- confidence: 필수. 인식 신뢰도이며 high=확실, medium=대체로 확실, low=불확실입니다.

예시(이미지에 이름과 코드가 함께 있을 때):
- 개별 종목: 600519 贵州茅台(구이저우마오타이), 300750 宁德时代(CATL)
- 홍콩 주식: 00700 腾讯控股(텐센트), 09988 阿里巴巴(알리바바)
- 미국 주식: AAPL 苹果(애플), TSLA 特斯拉(테슬라)
- ETF: 159887 银行ETF(은행 ETF), 512880 证券ETF(증권 ETF), 512000 券商ETF(증권사 ETF), 512480 半导体ETF(반도체 ETF), 515030 新能源车ETF(신에너지차 ETF)

출력 예시: [{"code":"600519","name":"贵州茅台","confidence":"high"},{"code":"159887","name":"银行ETF","confidence":"high"}]

["159887","512880"]처럼 코드 배열만 반환하면 안 되며, 반드시 객체 형식을 사용해야 합니다. 종목 코드를 하나도 찾지 못하면 []를 반환하십시오.
```

번역에서도 종목명은 화면에 표시되는 중국어 이름 그대로 두고 괄호에 한국어 설명을 붙였습니다. 모델은 이미지에 보이는 이름을 그대로 `name`에 넣기 때문입니다.
