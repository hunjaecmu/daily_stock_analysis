# 초보자용 클라이언트 설치와 설정 가이드

이 문서는 코드를 모르고 클라이언트를 내려받아 바로 쓰고 싶은 분을 위한 것입니다. 목표는 간단합니다. 클라이언트를 내려받고, 모델 서비스 키(Key)를 넣고, 종목 코드를 입력한 다음 첫 분석 리포트를 만드는 것입니다.

> 이 프로젝트가 만드는 것은 참고용 분석 리포트이며 투자 권유가 아닙니다. 실제 매매의 위험은 스스로 판단하세요.

## 먼저 준비할 것

1. Windows 또는 macOS 컴퓨터.
2. 모델 서비스 키(Key) 하나. 아래 중 하나를 고르면 됩니다.
   - [Anspire Open](https://open.anspire.cn/dsa?share_code=QFBC0FYC): 전 세계 주요 모델을 지원하며, Key 하나로 모델과 뉴스 검색을 함께 쓸 수 있어 처음 설정하기 가장 편합니다.
   - [AIHubMix](https://inferera.com/?aff=CfMq): 전 세계 주요 모델을 지원하며, 한 플랫폼에서 여러 모델을 바꿔 가며 쓰고 싶은 분께 맞습니다.
3. 분석하고 싶은 종목 코드. 예: `600519,hk00700,AAPL`.

## 1. 클라이언트 내려받기

릴리스 페이지를 엽니다.

<https://github.com/ZhuLinsen/daily_stock_analysis/releases/latest>

페이지 아래쪽 `Assets`(첨부 파일)에서 내려받습니다.

| 컴퓨터 | 내려받을 파일 |
| --- | --- |
| Windows | `daily-stock-analysis-windows-installer-<버전>.exe` |
| Windows(설치 없이 쓰기) | `daily-stock-analysis-windows-noinstall-<버전>.zip` |
| macOS Apple 칩 | `daily-stock-analysis-macos-arm64-<버전>.dmg` |
| macOS Intel 칩 | `daily-stock-analysis-macos-x64-<버전>.dmg` |

`latest.yml`, `*.blockmap`은 내려받지 않아도 됩니다. 클라이언트 설치 파일이 아닙니다.

Mac 칩 종류를 모른다면 왼쪽 위 Apple 아이콘 -> 이 Mac에 관하여를 눌러 보세요. M1/M2/M3/M4가 보이면 `arm64`, Intel이 보이면 `x64`를 고릅니다.

## 2. 설치하고 실행하기

- Windows 설치 파일: `.exe`를 더블클릭하고 안내에 따라 설치합니다. 설치 위치는 기본값 그대로 두면 됩니다.
- Windows 설치 없이 쓰기: `.zip`의 압축을 풀고 `Daily Stock Analysis.exe`를 더블클릭합니다.
- macOS: `.dmg`를 더블클릭하고 앱을 `Applications`로 끌어 놓습니다. 현재 DMG는 Apple Developer 서명과 공증을 받지 않아 Gatekeeper가 실행을 막을 수 있습니다. GitHub Releases의 공식 첨부 파일인 경우에만 "개인정보 보호 및 보안"에서 열기를 허용해 보세요. 전체 제약과 문제 해결 방법은 `docs/desktop-package.md`를 참고하세요.

macOS 사용자는 업그레이드하기 전에 클라이언트 설정에서 설정 백업을 한 번 내보내 두는 것을 권장합니다.

## 3. AI 모델 설정

클라이언트를 열고 다음으로 들어갑니다.

`系统设置 -> AI 模型`(시스템 설정 → AI 모델)

아래 방법 중 하나만 고르면 됩니다.

> 중요: 설정을 바꿀 때마다 페이지의 저장 버튼을 누르고, 저장 성공 안내가 보인 뒤에 다른 페이지나 홈으로 이동하세요.

### 방법 A: Anspire Open

1. [Anspire Open](https://open.anspire.cn/dsa?share_code=QFBC0FYC)을 열고 가입 / 로그인한 뒤 API Key를 만듭니다.
2. 클라이언트로 돌아와 빠른 채널 추가에서 `Anspire Open`을 고릅니다.
3. API Key를 붙여 넣습니다.
4. 모델 이름은 콘솔에서 사용 신청을 마친 모델을 고릅니다. 잘 모르겠다면 콘솔이 추천하는 모델이나 가벼운 모델을 먼저 고르세요.
5. 저장을 누르고, 저장 성공이 보이면 연결 테스트를 누릅니다.

### 방법 B: AIHubMix

1. [AIHubMix](https://inferera.com/?aff=CfMq)를 열고 가입 / 로그인한 뒤 API Key를 만듭니다.
2. 클라이언트로 돌아와 빠른 채널 추가에서 `AIHubmix（聚合平台）`(AIHubmix, 통합 플랫폼)을 고릅니다.
3. API Key를 붙여 넣습니다.
4. 모델 이름은 콘솔에서 사용 신청을 마친 모델을 고릅니다. 잘 모르겠다면 콘솔이 추천하는 모델을 먼저 고르세요.
5. 저장을 누르고, 저장 성공이 보이면 연결 테스트를 누릅니다.

테스트가 성공하면 다음 단계로 넘어갑니다.

## 4. 관심 종목 입력

다음으로 들어갑니다.

`系统设置 -> 基础设置`(시스템 설정 → 기본 설정)

`自选股列表`(관심 종목 목록)을 찾아 다음처럼 입력합니다.

`600519,hk00700,AAPL`

여러 종목은 영문 쉼표(,)로 구분합니다. 자주 쓰는 형식은 다음과 같습니다.

- A주(중국 본토 주식): `600519`, `300750`, `000001`
- 홍콩 주식: `hk00700`, `hk09988`
- 미국 주식: `AAPL`, `TSLA`, `NVDA`
- 한국 주식: `005930.KS`처럼 코스피는 `.KS`, 코스닥은 `.KQ`를 붙입니다.

입력한 뒤 저장을 누르고, 저장 성공이 보이면 홈으로 돌아갑니다.

## 5. 뉴스 소스 설정(권장)

뉴스 소스는 필수는 아니지만 설정하는 것을 권장합니다. 최근 뉴스, 공시, 이벤트, 화제 테마, 위험 안내에 영향을 줍니다.

다음으로 들어갑니다.

`系统设置 -> 数据源`(시스템 설정 → 데이터 소스)

쓰고 있는 모델 서비스에 따라 고릅니다.

1. Anspire Open을 쓴다면: `Anspire API Keys`를 찾아 같은 Anspire Key를 넣고 저장하면 끝입니다.
2. AIHubMix를 쓴다면: [SerpAPI](https://serpapi.com/github-daily-stock-analysis)나 [Tavily](https://tavily.com/)의 Key를 하나 더 받아 `SerpAPI API Keys` 또는 `Tavily API Keys`에 넣고 저장하면 됩니다.

일단 써 보고 싶다면 뉴스 소스를 건너뛰어도 됩니다. 클라이언트는 여전히 기본 분석을 만들 수 있습니다.

## 6. 분석 시작

홈으로 돌아가서:

1. 종목 코드를 입력합니다. 예: `600519`.
2. 분석을 누릅니다.
3. 작업 상태가 대기 중, 분석 중을 거쳐 분석 완료로 바뀔 때까지 기다립니다.
4. 기록에서 리포트를 확인합니다.

## 자주 묻는 질문

### 다운로드 페이지에 파일이 많은데 무엇을 받아야 하나요?

일반 Windows 사용자는 `.exe` 설치 파일을 받으면 됩니다. `latest.yml`이나 `*.blockmap`은 받지 마세요.

### API Key를 넣었는데도 안 돼요

다음을 확인하세요.

1. Key를 빠짐없이 복사했는지, 앞뒤에 공백이 없는지.
2. 플랫폼 계정에 잔액이나 사용 한도가 남아 있는지.
3. 지금 고른 모델의 사용 신청을 마쳤는지.
4. 연결 테스트에서 모델 없음, 권한 부족, 잔액 부족 같은 메시지가 나오는지.

### 설정이 꼬였어요

평소에 클라이언트 설정에서 설정 백업을 내보내 두세요. 문제가 생기면 이전 백업을 가져오거나, AI 모델, 관심 종목, 뉴스 소스 세 가지만 남기고 다시 설정하면 됩니다.
