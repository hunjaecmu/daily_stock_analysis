# 관심 종목 변화 상태와 다음 할 일

웹 홈 화면의 관심 종목 목록은 종목마다 현재 처리 상태를 한 줄로 모아 보여 줍니다. 아이콘, 작업 상태, 상세 화면 진입점에 흩어져 있던 정보를 한눈에 훑어볼 수 있는 세 가지 신호로 정리하는 기능입니다.

## 표시 구조

관심 종목마다 기존의 종목명, 코드, 최근 분석 시각, 점수 태그, 삭제 버튼, 클릭하면 최신 상세를 여는 기능은 그대로 두고, 간결한 신호 세 가지를 새로 추가합니다.

| 신호 | 의미 | 현재 데이터 출처 |
| --- | --- | --- |
| 변화 | 오늘 분석 목표 대비 이 종목의 변화 상태 | `analyzedToday`, `latestItem`, 오늘 상태 조회 결과 |
| 상태 | 완료, 업데이트 대기, 확인 중, 작업 실행 중 가운데 어느 상태인지 | `analyzedToday`, `activeTask`, 오늘 상태 조회 결과 |
| 다음 할 일 | 사용자가 다음에 가장 먼저 해야 할 일 | 최신 상세 사용 가능 여부, 작업 상태, 오늘 상태 |

## 상태 대응표

| 상황 | 변화 | 상태 | 다음 할 일 |
| --- | --- | --- | --- |
| 오늘 분석했고 최신 상세를 열 수 있음 | 오늘 업데이트됨 | 완료 | 최신 리포트 열기 |
| 과거 리포트는 있지만 오늘은 분석하지 않음 | 과거 리포트 있음 | 업데이트 대기 | 오늘 분석 실행 |
| 과거 리포트가 하나도 없음 | 첫 분석 대기 | 업데이트 대기 | 오늘 분석 실행 |
| 오늘 상태를 확인하는 중 | 확인 중 | 확인하는 중 | 상태 확인 기다리기 |
| 오늘 상태 조회가 실패했거나 알 수 없음 | 상태 알 수 없음 | 새로고침 필요 | 새로고침해서 확인 |
| 실행 중이거나 대기 중인 작업이 있음 | 기존 변화 상태 유지 | 작업 상태 | 작업 완료 기다리기 |

## 동작 범위

- 관심 종목 본문을 클릭하면 여전히 최신 리포트 상세만 엽니다.
- 상세가 없거나, 상세를 조회 중이거나, 상세 상태를 알 수 없으면 기존 안내 문구를 계속 보여 줍니다.
- 삭제 버튼은 따로 동작하며, 눌러도 상세가 열리지 않습니다.
- 이번에는 종목별 즉시 분석 버튼을 추가하지 않습니다. 기존 일괄 분석 버튼과 제출 의미가 겹치지 않게 하기 위해서입니다.

## 이후 확장

- 실시간 등락률을 연결하면 `변화`를 "리포트가 있는지"에서 "가격 변화 + 의견 변화"로 확장할 수 있습니다.
- ResearchArtifact를 연결하면 `상태`에서 thesis(투자 논리)가 발동했는지 또는 무효가 되었는지 보여 줄 수 있습니다.
- 엔터티 이동 모델을 연결하면 `다음 할 일`을 실제로 실행할 수 있는 동작으로 바꿀 수 있습니다. 예를 들어 리포트 작업 공간 열기, 모니터링 만들기, 포트폴리오에 추가하기 등입니다.
